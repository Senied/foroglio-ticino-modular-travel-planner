## Release status

The frozen v1.3 files passed the publication gate:

1. The release manifest inventories the seven public filenames.
2. The checksum list covers the six files inside the downloadable bundle.
3. Desktop and mobile browser checks passed without horizontal overflow or console errors.
4. Search, the module builder and the photo lightbox were functionally tested.
5. All 75 PDF pages were rendered at 180 dpi and visually reviewed; all 490 PDF links were retained.
6. The photo manifest records 45 distinct public-safe images, their P001–P045 IDs, sources, creators and licences.

All website links are relative so the tree works on GitHub Pages project paths as well as a local HTTP server.
